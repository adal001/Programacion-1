# Programación 1

Este repositorio contiene los programas y ejercicios
desarrollados durante la materia de Programación 1.

Los ejercicios están organizados por temas, y cada
programa se encuentra en su propia carpeta.

## Programas incluidos

### Calcular áreas
Programa que calcula el área de un triángulo, círculo o un rectángulo, hasta que
el usuario desee "Salir".

### Cantidad días del mes
Programa que, dado un año (>1582) y un mes (1:Enero, 2:Febrero,…, 12:Diciembre),
indica el número de días de ese mes en ese año.

### Es vocal
Programa que captura un carácter e indica si es una vocal: a, e, i, o, u, A, E,
I, O, U, á, é, í, ó, ú, Á, É, Í, Ó, Ú, ü, Ü

### Formato fecha
Programa que, dados tres números enteros correspondientes a una fecha de
nacimiento: año, mes, día, obtiene una cadena de longitud 6, donde los dos
primeros caracteres son los dos últimos dígitos del año, los siguientes dos
corresponden al mes (0x para meses de 1 dígito) y los últimos dos corresponden
al día (0x para días de 1 dígito).

### Genio y figura
Programa que imprime figuras rellenas (reloj de arena, rombo, moño, copa).

### Juego número mágico
Programa que lleva a cabo el juego del número mágico.

### Lista números
Programa que captura n números, los almacena en una lista y construye una
segunda lista con los elementos de la lista original sin repeticiones.

### Piedra, papel, tijera
Programa que lleva a cabo el juego de piedra, papel o tijera entre la máquina y
el usuario.

### Promedio calificaciones
Programa que calcula el promedio de n calificaciones dadas en el rango [0, 100].
El valor n es un entero positivo.

### Tabla multiplicar N
Programa que lee un entero n y escribe la tabla de multiplicar de n (de 1 a 10).

### Nombre, edad, peso usuario
Programa que captura el nombre, la edad y el peso del usuario y los imprime
juntos con el formato: XXXXXXXXX, tienes XX años y pesas XX.XX kg.

## Ejecución de un programa

### Nombre, edad, peso usuario
Abre el archivo principal y proporciona los tres datos que solicita el programa.
